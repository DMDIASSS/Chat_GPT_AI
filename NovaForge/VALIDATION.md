## Upstream packaging detail

RocketSim 2.2.1 advertises ABI3 wheels. The inspected internal Windows wheel metadata instead names CPython 3.11, so `0_INSTALL.bat` selects **Python 3.11 x64**. The Linux wheel's internal metadata names CPython 3.9 and can make `pip check` report an unsupported platform under 3.11/3.12, despite the actual module and physics tests succeeding. Dependency resolution otherwise completed. This package does not modify upstream wheel metadata. The doctor and functional smoke checks are used for installation verification; the viewer metadata exception is documented in the v1.5.3 hotfix.
