# RocketSimVisWeb

My three.js rewrite of [RocketSimVis](https://github.com/ZealanL/RocketSimVis) for [RocketSim](https://github.com/ZealanL/RocketSim)

<img width="362" height="330" alt="image" src="https://github.com/user-attachments/assets/ec028ca5-447e-4fc2-87b9-4183b472acd1" />

This visualizer was built with the intention of replicating RocketSimVis's simple look while offering support for rendering in browsers

## Credits

All models and design choices created and inspired by [ZealanL](https://github.com/ZealanL)

## Setup

Follow the same setup as [RocketSimVis](https://github.com/ZealanL/RocketSimVis)

## Running the visualizer 

Run `RUN.bat` on windows or `server.py`
