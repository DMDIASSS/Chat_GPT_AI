The installed RLGym-tools 2.6.5 `pick_action.py` also compares effective dodge direction `(pitch, yaw + roll)`. The event label confidence now follows that equivalence: a valid yaw-directed dodge is not rejected merely because the native 90-action table expresses the same direction with roll. This does not claim identical continuous controls or a perfect entire replay trajectory.

The normal replay bank audit supplied by the user reported 7.47% idle target mass and 9.70% grounded idle mass, across 70,026 training rows. That contradicts a simple claim that the new bank mostly contains idle labels. The older 3711232 policy's 93% idle probability is reproduced, but the original cause is not established. The binary bank exceeds the cloud tool's 32 MiB transfer limit; its JSON metadata/audit were read, while its full bytes were not analyzed.
