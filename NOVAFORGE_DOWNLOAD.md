# NovaForge 1.14.0 / ForgeLeague 0.1

[Download the complete source update](https://github.com/DMDIASSS/Chat_GPT_AI/raw/refs/heads/codex/novaforge-v1/downloads/NovaForge-ForgeLeague-v1.14.0.zip)

The ZIP contains chat_gpt_ai/novaforge, chat_gpt_ai/triadbot and chat_gpt_ai/forgeleague. Pause existing trainers, merge those folders into your existing Chat_GPT_AI, replacing program files while preserving .venv/assets/runs/exports. No new dependency installation is required for an existing NovaForge 1.13 runtime.

Open forgeleague/0_CHECK.bat, then 1_CREATE.bat, then 2_START_OR_RESUME.bat. The new duel01 run trains two independent Chronos-family and Galactus V2-family actors on Octane. It uses your selected frozen Fusion initialization for the Chronos family when available, otherwise explicitly reports original Chronos. Existing selector/Fusion runs remain available and are not reset. Do not run multiple trainers on the laptop.

The controlled pilot compares ordinary and privileged critics; exported actors never receive private information. The serial league includes frozen snapshot opponents, curriculum challengers, bounded concession-focused sampling, complete optimizer checkpoints, paired WDL with fresh confirmation, regression halts, reports, W&B and independent RLBot v5 exports (.lt, identical .pt, TOML and loader).

[Step-by-step launchers, reward formula, safeguards and limitations](ForgeLeague/README.md) · [Research decisions and validation](NovaForge/FORGELEAGUE_v0.1.md) · [Validation record](NovaForge/VALIDATION.md)

Use 3_PAUSE to stop, 4_REPORT to package diagnostics, and 5_EXPORT_RETAINED_BOTH_V5 to export both retained champions. On this PC import each export's bot.bot.toml; on a second PC run INSTALL.bat and import bot.portable.bot.toml. Watch with 6/7. A retained initialization may be exported if no improvement passed; exporting alone is not evidence of stronger play.

Source only: no teacher weights, private user reports or keys. Playing strength, long training and live-game transfer require measured evaluation. No guaranteed reward result, team coordination or 10x/100x GigaLearn speedup is claimed. Published on codex/novaforge-v1; main is unchanged.
